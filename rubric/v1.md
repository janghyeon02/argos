# 아르고스 평가 기준표 v1

> DESIGN.md 6장에서 옮긴 초안. 과거 사례 검증(PLAN 17번)에서 숫자를 조정하고, 바뀌면 새 버전 파일(v2.md …)로 남긴다.
> 숫자 자체는 `lib/config/rules.ts`가 기준이며, 이 문서는 AI에게 보여 주는 판단 기준과 사람이 읽는 설명이다.

## 1. 영향도 (0~100)

한국으로 들어오는 6개 경로를 각각 0~5점으로 매긴다.

| 점수 | 뜻 |
|---|---|
| 0 | 없음 |
| 1 | 미미함 — 이론상 연결은 있지만 체감되기 어려움 |
| 2 | 제한적 — 일부 업종·품목·시장에 영향 |
| 3 | 뚜렷함 — 관련 지표(수출·환율·금리 등)에 눈에 띄는 변화 가능 |
| 4 | 큼 — 한국 경제 전반이나 주요 시장에 상당한 충격 가능 |
| 5 | 매우 큼 — 위기 수준의 충격 가능 |

| 경로 | 보는 것 |
|---|---|
| 수출·통상 | 관세·수출 규제·주요 교역국 수요 변화 |
| 에너지 가격 | 원유·가스·전력 가격과 공급 |
| 환율·자본 유출 | 원화 가치, 외국인 자금 이동, 신용 위험 |
| 금융시장 전염 | 주식·채권·은행 시스템으로 번지는 충격 |
| 공급망 | 반도체·부품·원자재·물류 차질 |
| 교민·안보 | 한반도 안보, 해외 교민 안전, 군사 충돌 |

- 기본 점수 = (가장 높은 경로 점수 × 14) + (나머지 5개 경로 점수 합 × 2), 최대 100
- 가산점 +10: 미국·중국·유로존·일본이 진원이거나 한국이 직접 진원이면 (최대 100)

## 2. 가능성 (0~100)

| 요소 | 점수 | 기준 |
|---|---|---|
| 압력 지표 | 0~40 | 공개 자료에 나온 구조적 압력의 크기 (재정 적자, 국채 금리 급등, 지지율 급락, 시위 규모 등). 근거 기사에 실제로 나온 내용만 쓴다 |
| 예정된 계기 | 0~30 | 결정·발표·표결·선거 같은 예정된 날이 7일 이내 30, 30일 이내 20, 90일 이내 10, 없음 0 |
| 촉발 신호 | 0~30 | 켜진 신호 1개당 10점 (공식 경고, 최후통첩, 신용등급 하향, 긴급회의, 실제 무력 충돌 등) |

## 3. 속도 (0~100, AI 없이 계산)

- 최근 6시간 자료 수(1등급 1.5, 2등급 1.2, 3등급 1.0, "(카더라)" 0을 곱해 더함) ÷ 직전 7일의 6시간 평균(최소 1)
- 비율 1.5 미만 10점, 1.5~3 30점, 3~6 50점, 6~12 70점, 12~24 85점, 24 이상 100점
- 가중 자료 수가 3 미만이면 최대 30점

## 4. 종합 점수와 등급

1. 5번 평가 각각에서 종합 점수 = 영향도 × max(가능성, 속도) ÷ 100 을 계산하고 중앙값을 쓴다.
2. 1·2등급 정식 근거가 없으면 최대 79점('심각' 불가).
3. 관심 0~39 / 주의 40~59 / 경계 60~79 / 심각 80~100, 구간 경계 ±3점 안이면 '경계선'.
4. 등급을 내릴 때는 연속 두 번의 실행에서 모두 낮게 나와야 내린다.

## 5. 근거 규칙

- 축마다 점수의 근거가 된 기사 번호를 적는다. "(카더라)"·정정·철회된 기사는 근거로 쓰지 않는다.
- 근거가 없는 축은 0점이다.
- 기사에 없는 사실·수치를 짐작해서 점수를 올리지 않는다.
